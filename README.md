# OMA v2

Principal과 Worker가 메일과 Git으로 협업하는 코딩 에이전트다.

프로젝트 문서는 [docs/README.md](docs/README.md)에 모았다. [실행·운영 안내](docs/operations.md), [현재 재개점](docs/HANDOFF.md), [검증 상태](docs/implementation/validation.md)를 여기서 찾을 수 있다.

checkout 설치 안내는 Linux용이다. macOS의 앱·VM 배포물은 이 저장소에서 제공되지 않으며, `npm install -g .`만으로 Mac 제품을 실행할 수 없다. 필요한 환경과 최초 snapshot에 포함되는 파일은 실행·운영 안내를 먼저 확인한다.
