# Native 외부 구현 조사 자료

[고정 commit을 사용한 조사 원문](../archive/cleanup-2026-11-03/implementation/native-reference-review.md)에 외부 저장소의 source, 관측과 당시 한계를 보관했다. 이 기록은 현재 외부 프로젝트의 동작이나 OMA 플랫폼 지원 완료를 보증하지 않는다.

현재 구현 기준은 [플랫폼 계약](../macos-platform.md)·[native 명세](../macos-native-spec.md), 실행 근거는 [검증 상태](validation.md)에 있다.
