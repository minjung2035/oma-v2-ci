# 과거 unit 계약의 참조 위치

이 디렉터리는 고정된 architecture 원문의 상대 링크를 보존한다. DR49로 unit runtime과
template의 production 경로는 폐기했다. 당시 bytes는 [과거 renderer](../../archive/systemd-reference-2026-10-26/packages/platform-linux/src/systemd)에 보존한다.
현재 실행 계약은 [native 규범](../../macos-platform.md), 구현·검증 상태는 [전환 기록](../native-transition.md)이 소유한다.
