# 작업 상태 안내

현재 결과는 [검증 상태](implementation/validation.md), 실행 방법은 [유지보수 안내](MAINTENANCE.md), 구현 기준은 [PRIORITY-0](PRIORITY-0.md)와 [협업 표면 명세](model-collaboration-surface-spec.md)에 있다.

이전 작업자의 재개 순서·금지 지시·부분 PASS를 새 작업의 지시나 현재 상태로 사용하지 않는다. 현재 사용자 요청이 작업 범위를 정한다. 이 파일에는 별도의 작업 지시나 검증 수치를 중복해서 기록하지 않는다.

[정리 전 인계 원문](archive/cleanup-2026-11-03/HANDOFF.md)은 당시 주장과 원시 근거를 추적하기 위한 역사 자료다.
